# Blender Container Project

## Last Updated: August 27, 2026

---

## Project Overview
Designing a 3D-printable watertight container for 3D printer filament or tools.

## Specifications
- **Inner Diameter:** 66mm
- **Inner Height:** 140mm
- **Wall Thickness:** 3mm
- **Base Thickness:** 6mm
- **Thread Height:** 18mm
- **Lid Height:** 26mm
- **Carabiner Hole:** 12mm
- **O-ring:** 70mm OD x 2mm cross-section

## Features
- Helical threads (male on body, female in lid)
- 10 elongated grip indents
- Knurled design bands (32 notches each)
- Carabiner loop with reinforced ring
- O-ring gland for waterproof seal
- JSF/3D3SIGNS logo embossed on body

## Files
- `container_v7.py` — Latest Blender Python script
- `container_v7.png` — Render preview

## 3D Printer
- Bambu H2D or H2C
- Material: PLA or PETG
